# Laboratório de prompts e IA com dados de vendas

Exercício de estudo com arquivos CSV para explorar análises e experimentos de prompts usando uma estrutura de vendas multicanal. Este repositório contém somente conjuntos de dados de exemplo; não inclui uma aplicação, pipeline ou integração de produção.

## Dados de demonstração

Os quatro CSVs foram substituídos por amostras sintéticas:

- `Meganium_Sales_Data_-_AliExpress.csv` — 20 linhas de exemplo.
- `Meganium_Sales_Data_-_Etsy.csv` — 20 linhas de exemplo.
- `Meganium_Sales_Data_-_Shopee.csv` — 20 linhas de exemplo.
- `Meganium_Sales_Consolidated_NETZ.csv` — 60 linhas combinadas.

Os nomes de compradores, SKUs e números de fatura são identificadores fictícios com prefixo `SYN`. O campo `buyer_birth_date` foi mantido vazio para preservar o formato sem publicar datas pessoais. Todos os preços são valores demonstrativos em USD; não representam transações reais.

## Uso responsável

Use os arquivos somente como dados de demonstração. Não substitua os exemplos por dados reais de clientes, nomes, datas de nascimento, faturas ou outros identificadores pessoais antes de publicar o repositório. A branch atual contém amostras sintéticas; commits anteriores podem ainda preservar versões antigas dos CSVs no histórico Git.
